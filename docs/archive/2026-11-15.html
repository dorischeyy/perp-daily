November 14: Pacifica adds one-cancels-the-other orders to its mobile app

Pacifica’s mobile app now lets traders place two linked orders. When one fills, the system automatically cancels the other. Traders can use them for breakout or pullback entries and position exits. The announcement did not explain how the system handles network delays, partial fills or a failed cancellation.

On November 14th, Variational added Scale Orders and Cancel All.

Variational Omni has added a feature called “Scale Orders.” This allows for the automatic placement of multiple limit orders within a set range. It also includes a function to cancel all pending orders with one click. The order panel has been improved, with better display of price differences. This feature is suitable for stratifying positions and quickly reducing risks. However, the official documentation does not specify the maximum number of batch orders or the delay in canceling orders during extreme market conditions.
