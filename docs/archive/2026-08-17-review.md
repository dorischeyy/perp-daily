## A0 读者价值自问

1. **为什么今天值得点开？**：四个主要永续场所成交增长 18.0%，但 OI 只增 0.1%；同时 LaunchFair、GMGN 与 OCC 分别推进发行约束、资产发现和稳定币银行化路径。
2. **最值得看的是什么？**：Hyperliquid 成交增长 44.1%，OI 与成交比从 10.84 降至 7.54，说明单日退出周转改善比名义持仓增长更明显。
3. **哪项原有判断被更新？**：从把成交恢复视为容量改善证据，改为只有连续 OI 与成交比、资产级盘口和退出冲击共同改善才调整容量。
4. **看完后能做出什么更好的决定？**：HertzFlow 应维持当前动态容量上限，优先用滚动周转、盘口深度和退出冲击复核流动性，不因一天成交放大就调整风控参数。
5. **什么证据会推翻今天的结论？**：若连续多日 OI 上升、OI 与成交比稳定下降，并且资产级深度增加、退出冲击低于现有阈值，则可以推翻暂不放宽容量的结论。
6. **哪条内容只是新闻复述？**：已删除过期的 AgentOS、OpenAI 和微软产品更新，也没有收录普通新币上架、币价波动和缺少可核验发布日期的活动页。

### 六视角找茬

1. **一线交易员或巨鲸**：场所级 BTC 聚合不能证明资产级退出深度，正文把成交反弹写成周转信号，没有写成永久容量扩张。
2. **竞品产品负责人**：GMGN 与 LaunchFair 的提交能证明工具和配置上线，不能证明用户采用或成交转化，正文保留了边界。
3. **CEO 或战略**：OCC 条件批准和银行合作说明受监管入口前移，但一个尚未开业、一个计划 2027 年上线，不能提前计入收入。
4. **怀疑论者**：OpenRouter 收购来自媒体报道且 Stripe 未置评，标题和正文均保留据报口径。
5. **主编**：Perp DEX 三条分别覆盖总体周转、Hyperliquid 单场所与 Gate、Bybit 的跨场所验证，没有重复昨日结论。
6. **新人**：正文解释 OI 与成交比、条件批准、不可变费用和水印边界，不要求读者自行补机制。
