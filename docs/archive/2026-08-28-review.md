1. **为什么今天值得点开？**：KuCoin 首次把盘前、开放、结算和关闭拆成统一合约 API 状态，Bitrue 同日展示硬下架时剩余仓位如何处理，市场生命周期从运营文案进入交易系统接口。

6. **哪条内容只是新闻复述？**：已删除只有新币名称、单一上币规格或公司宣传而没有机制与边界的候选；所有入选条目都补了权利、量级或落地限制。
