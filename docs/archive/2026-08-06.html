World Chain plans to stream access lists every 200 milliseconds for parallel verification on a production Layer 2

Event: World Chain plans to activate EIP-7928 block access lists on mainnet on August 17 and stream them with Flashblocks about every 200 milliseconds. It says it would be the first production layer-2 network to use full access lists.

Mechanism: An access list identifies the accounts and storage slots a transaction reads or writes and records resulting state changes. Validators can execute independent transactions in parallel without waiting to replay a whole block sequentially. The tests aim to improve verification throughput without raising node hardware requirements.

Second-order effects: Similar trading infrastructure would need external validators to reproduce state changes as well as a sequencer to promise low latency. The launch date, sustained verification latency and one billion gas per second remain plans or test results. Mainnet measurements are still needed.

ImplementationMainnet activation is scheduled for August 17. One billion gas per second is the team's test target, not measured production throughput or a direct equivalent of transactions per second.
