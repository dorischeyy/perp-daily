# 编辑自评

## A0 读者价值自问

1. **为什么今天值得点开？**：比特币期货年化基差约 3%，已经低于两年期美债约 3.8%，永续竞争由提供杠杆转向证明净收益与风险吸收能力。
2. **最值得看的是什么？**：同一无到期日合约的尾部风险主要由场所的保证金、指数和违约瀑布决定，合约形式本身不是充分解释。
3. **哪项原有判断被更新？**：从只展示历史资金费率和基差，改为把费用、融资和保证金占用后的净 carry 与无风险收益并列。
4. **看完后能做出什么更好的决定？**：优先建设净 carry 面板、异常指数与清算瀑布披露，再扩展更多可定价标的。
5. **什么证据会推翻今天的结论？**：若比特币基差重新稳定高于低风险美元收益，且扣费后的套利资本显著回流，则净 carry 的紧迫性下降；若不同场所在压力行情下损失表现无明显差异，则场所设计的解释力需要下调。
6. **哪条内容只是新闻复述？**：已删除没有机制变化的常规上币、奖励和行情快讯；所有保留条目都补充了机制、边界或对产品的二阶影响。

1. **一线交易员/巨鲸**：3% 基差不等于可实现收益，必须扣除双腿交易、融资、托管、保证金与展期成本；正文已避免把名义基差当净收益。

5. **主编**：四栏各三条，lead 由当日硬数字驱动，没有重复 08-03 的 RWA 成交、美国税务、Bybit 抵押品或 Claude 评测。
6. **新人**：正文解释了基差、carry、清算瀑布、只减仓、replace-by-fee 和机器可读标记的实际含义。
