# Perp DEX Daily 编辑自评

## A0 读者价值自问

**为什么今天值得点开？**：托管、执行和退出正在成为永续平台的新竞争层，股票永续的股息也开始暴露权利结算并不等同于持有现货。

**最值得看的是什么？**：Bitget把外部托管资产镜像进现货、保证金和期货，但没有披露镜像结算和异常退出时限；这比“降低托管风险”的宣传更值得继续核验。

**哪项原有判断被更新？**：从“非加密永续主要比标的和杠杆”转向“托管位置、公司行动、休市价格、网络恢复与抵押品计划需要分别判断”。

**看完后能做出什么更好的决定？**：评估同类产品时，可以把已上线、计划上线、可交易、可提币和可独立验证分开，不再用单一状态概括全部可用性。

**什么证据会推翻今天的结论？**：若外部托管镜像能在清算和异常期间即时结算、股票永续公司行动能无延迟自动映射，或计划中的永续与抵押已经实际开放，则需上调相关产品成熟度。

**哪条内容只是新闻复述？**：已删除没有改变执行、托管、权利、退出或Agent控制判断的普通扩列和版本更新。
